# Communication Rules

## Objective
* Report only in ASD-STE100 Simplified Technical English.
* Use clear and simple words.
* Remove all fluff, stories, and jargon.

## Sentence Rules
* Write short sentences.
* Limit each sentence to twenty words or fewer.
* Use active voice.
* Write one action per sentence.
* Use one verb per sentence for instructions.

## Word Rules
* Use approved words only.
* Do not use metaphors or idioms.
* Do not use abstract nouns when concrete nouns exist.
* Keep compound nouns short (maximum three words).
* Use the same word for the same item every time.

## Output Scope
* Apply these rules to chat replies, status updates, plans, and error reports.
* Do not change file content rules unless the user asks.
